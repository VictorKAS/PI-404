Hierarquia de seletores e especificidade

Quando duas regras mudam a mesma propriedade do mesmo elemento, o navegador precisa escolher uma. Essa escolha segue a hierarquia dos seletores, chamada de especificidade.

Como o navegador decide

  1. Compara a especificidade: quanto mais específico o seletor, maior o peso.
  2. Se o peso empatar, vence a regra escrita por último no CSS.
  3. O !important passa por cima de tudo (use só em último caso).

Tabela de pesos (inline - id - classe - elemento)

TipoExemploPeso
Estilo inlinestyle="color: green"1-0-0-0
id#alvo0-1-0-0
Classe, pseudo-classe, atributo.destaque, :hover, :nth-child()0-0-1-0

Para somar, conte cada tipo. Exemplo: #menu a:hover tem 1 id, 1 pseudo-classe e 1 elemento, ou seja, 0-1-1-1.

html e :root

O :root é o próprio elemento html. Guarda variáveis do CSS inteiro, e o html define o tamanho base do texto.

html

Seleciona o elemento , que é a raiz do documento HTML​

:root​

É uma pseudo-classe que representa o elemento raiz do documento.​

Ou seja:​

Em HTML, a tag html e a pseudo-classe :root correspondem ao elemento ​

ENTÃO PARA O QUE USAMOS :root?​

:root é muito utilizado para criar variáveis CSS globais, que podem ser reutilizadas em diferentes partes do código.​

:root {
  --cor-principal: teal;
}
.quadrado {
  background: var(--cor-principal);
}
html.grande {
  font-size: 22px;
}

:link e :hover

O link começa azul (:link) e fica vermelho com sublinhado quando o mouse passa por cima (:hover). O botão simula o :hover.

:link​

O :link é uma pseudo-classe do CSS que seleciona links que ainda não foram visitados. Ele permite estilizar a aparência desses links, como a cor e o sublinhado.​

Importante: O :link e o :visited são mutuamente exclusivos.​​

:hover

O :hover é uma pseudo-classe que permite mudar a aparência de um elemento quando o usuário passa o cursor mouse ele. É muito criar o cursor do mouse sobre ele. Combinador +

Seleciona o elemento que vem imediatamente depois de outro, se forem irmãos.

Combinador de irmão adjacente

O combinador + seleciona um elemento que aparece imediatamente depois de outro elemento, desde que sejam irmãos.​

.irmaos.ativo h4 + p {
  color: blue;
}

Título

Este p vem logo depois do h4.

Backdrop-filter

Desfoca o que está atrás do elemento. A faixa está sobre dois círculos coloridos.

O backdrop-filter é uma propriedade do CSS que permite aplicar efeitos gráficos — como desfoque (blur), mudança de cor ou contraste — à área que fica atrás de um elemento. Em vez de alterar o elemento em si, ele age como se o elemento fosse uma lente ou um vidro que distorce ou recolore o que está no fundo.

A Regra de Ouro

1. O efeito só é visível se o elemento tiver um fundo parcialmente transparente.

2. Usar uma cor sólida (como background: white) bloqueia totalmente o efeito.

3. A solução: Sempre combinar com cores RGBA (ex: background-color: rgba(255, 255, 255, 0.2)).

A Diferença entre filter e backdrop-filter

1. filter: Aplica o efeito ao próprio elemento e a todo o seu conteúdo (incluindo textos e imagens filhas). Se você aplicar filter: blur(5px); a uma div, o texto dentro dela também ficará embaçado e ilegível.

2. backdrop-filter: Aplica o efeito apenas ao que está por trás do elemento. O conteúdo interno (como textos e botões) permanece 100% nítido, garantindo a legibilidade.

.fundo.ativo .vidro {
  backdrop-filter: blur(10px);
}
